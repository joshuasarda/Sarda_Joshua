# Portfolio website starter

## Run locally
Open `index.html` in a modern browser. No build tools or installation are required.

## Customize first
1. The portfolio is personalized with the name `Ajdhine Barbon`. Update it if needed.
2. Replace the profile photo URL in `.profile-photo` with your own image.
3. Replace the sample projects with your actual projects, descriptions, screenshots, role, tools, and outcomes.
4. Update education, experience, skills, and writing samples.
5. Change `hello@example.com` to your preferred contact email.
6. Update social links if you want to add LinkedIn, GitHub, Instagram, or other profiles.

## Included
- Responsive desktop and mobile layout
- Persistent light/dark theme toggle with readable contrast
- Circular profile image on the left side of the hero
- About, projects, skills, experience/education, writing, and contact sections
- Mobile navigation, keyboard focus styling, reduced-motion support, and scroll reveal effects

The portrait and project photography currently use remote Unsplash URLs, so those images need an internet connection. Replace them with local assets if you want the site to work fully offline.
